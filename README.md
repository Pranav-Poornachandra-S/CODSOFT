A collection of foundational C++ console applications developed during my internship, demonstrating core programming concepts including recursion, array manipulation, control flow logic and interactive terminal games.

---

## Projects Breakdown

### 1. Random Number Guessing Game
A CLI-based pseudo-random game that generates a target integer using time-seeded randomness.
* **Key Mechanics:** A `do-while` loop for continuous feedback, dynamic higher/lower hint generation and input processing.

### 2. Simple Calculator
A multi-operation arithmetic calculator supporting addition, subtraction, multiplication, division, modulo and exponentiation.
* **Key Mechanics:** Custom recursive exponent function, divide-by-zero validation and `switch-case` dispatching.

### 3. Tic-Tac-Toe
An interactive 2-player terminal board game with state tracking and automatic win/draw evaluation.
* **Key Mechanics:** 2D array matrix state evaluation, turn switching logic, input validation and replay loop.
